## 🔴 GEN-TOOL — Édition Crimson ULTIME V2

> *"Code is poetry. Hacking is art."*

**GEN-TOOL** est un multi-tool tout-en-un pour les tests de sécurité, l'OSINT et l'analyse réseau. Il regroupe **plus de 50 modules fonctionnels** dans une interface en ligne de commande, avec un design épuré et des animations.

> ⚠️ **Avertissement :** Cet outil est destiné à un usage éducatif et de test de sécurité. L'utilisateur est seul responsable de l'utilisation qu'il en fait.
